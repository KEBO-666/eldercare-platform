作品：社区智慧养老服务与健康监测平台

## 使用范围

本项目使用下列通用框架和工具完成 Web 接口、数据持久化、模板渲染、加密、调度、图表及测试。
业务实现的位置：app/services、app/algorithms、app/core/state_machine.py；架构和关键算法见 design.md。
本清单标明可核实的第三方组件来源，不替代参赛者对作品独立完成情况的确认。
