# 演示视频脚本（8～10 分钟）

> 目标：按赛题「评分标准」覆盖 —— 主流程端到端 + **至少一次异常处置** + 算法可解释 + 权限安全。
> 录制建议：1920×1080，浏览器缩放 110%，提前 `python -m scripts.seed` 准备好演示数据。

---

## 0:00–0:35　开场（一句话讲清问题与方案）

**画面**：登录页（适老化大字号）

**台词**：
> 我国 60 岁以上人口 3.23 亿，九成居家养老，但社区养老仍停留在纸质台账和电话微信。我们做的平台，把「档案—预约—派单—服务—预警—结算—监管」全链路搬到一个系统里，用 Python + FastAPI 实现。

**动作**：展示登录页，说明 6 类角色。

---

## 0:35–1:20　角色与权限（10 分：权限与数据安全）

**动作**：
1. 用 `super` 登录 → 系统管理 → 用户列表、角色权限矩阵；
2. 切换到 `grid1`（网格员）→ 页面只剩本网格数据；
3. 打开浏览器开发者工具或直接演示：用 grid1 的 token 请求别的网格老人 → 返回 403。

**台词**：
> RBAC 六个角色、三十五项权限点，再叠加四档数据范围；越权在服务层就被 SQL 条件拦住。

---

## 1:20–2:40　老人档案与隐私（30 分功能 + 10 分安全）

**动作**：
1. 档案列表：筛选「失能等级=中度」「标签=独居」；
2. 列表里身份证、手机、住址都是脱敏的；
3. 进入详情 → 点击「申请查看完整信息」→ 填写理由 → 10 分钟内可查看，页面底部显示二次授权留痕；
4. 变更一位老人的能力等级 → 展示「变更日志」前后值对比；
5. 系统管理 → 审计日志 → 展示刚才的操作记录，点击「校验审计链」→ 链完整。

**台词**：
> 敏感字段 AES-GCM 加密 + HMAC 摘要检索，查明文要二次授权并留痕；所有变更进变更日志，所有关键操作进哈希链审计。

---

## 2:40–5:00　主流程：预约 → 派单 → 服务 → 评价（15 分流程闭环 + 13 分算法）

**动作**：
1. 家属（elder1）登录 → 预约「明天 14:00 助浴」→ 提交成功，状态「待受理」；
2. 再提交一次同时段预约 → 系统提示冲突，需联系网格员人工协调（三重校验；当前不生成独立人工受理队列）；
3. 切网格员 → 受理 → 转待派单 → 打开派单页：展示 **Top3 候选 + 四项因子进度条 + 分数**；
4. 现场把权重从 0.4/0.3/0.2/0.1 改成 0.2/0.2/0.4/0.2 → 重新查询 → **排序变化**（算法可配置、可解释）；
5. 选定护理员派单 → 工单生成，价格快照显示；
6. 切护理员（nurse1）→ 工单列表 → 接单 → 签到；
7. 签到定位故意偏离 300 米 → 系统要求填写说明（"小区门禁，地址标注偏差"）→ 提交；
8. 逐项勾选（助浴、擦身、更衣、指甲修剪）→ 上传 2 张现场照片（第 4 张会被拒绝）；
9. 签退 → 填写小结并录入血压 `152/88` → 系统标记时长正常；
10. 切回家属 → 评价 4 星 → 护理员绩效回写。

**台词**：
> 一次服务从预约到评价全程留痕：签到有定位、过程有勾选和照片、签退有小结和体征。

---

## 5:00–6:40　异常处置：红色预警（15 分流程闭环核心）

**动作**：
1. 模拟可穿戴设备上报：收缩压 182 → 系统立刻生成**红色预警**，置顶显示；
2. 打开预警详情：推送记录显示"已推送网格员、家属、签约医生"（站内 + 模拟短信）；
3. 说明红色预警满 30 分钟未处置才升级；扫描按钮会立即检查已到期预警，不会加速时间。使用已到期演示记录或展示端到端超时用例；
4. 网格员到场处置 → 闭环结论选「已转诊」→ 填写转诊医院与时间；
5. 再上报一次"设备脱落"导致的异常 → 闭环为「误报」→ 统计页误报率更新。

**台词**：
> 红色预警 5 分钟内三方推送、30 分钟未处置自动升级，闭环必须落到三种结论之一，全过程可算响应中位数。

---

## 6:40–8:00　结算与差异核查（30 分功能 + 13 分算法）

**动作**：
1. 管理端 → 结算 → 生成上月账单；
2. 账单详情：政府补贴 / 长护险 / 个人自付三列；
3. 展示差异清单：重复计费、未完成计费、时长超 3 倍各一条，每条可填写说明与处理；
4. 差异率 > 1% → 账单标记"需人工复核"，直接确认被拦截；
5. 填写复核意见后确认 → 缴费登记；
6. 演示投诉结论"成立 → 退费" → 生成红冲账单，原账单金额不变；
7. 导出 Excel 账单。

**台词**：
> 价格按工单快照结算，补贴受月度上限约束，四类差异自动拦截，差异率超 1% 必须人工复核。

---

## 8:00–9:20　统计看板（30 分功能 + 13 分算法）

**动作**：
1. 社区端看板：服务量、覆盖率、待办工单、预警时效；
2. 机构端：护理员负荷、绩效排行、收入结构；
3. 街道端：各社区对比、补贴支出、满意度分布；
4. 图表覆盖：趋势折线、占比饼图、排行条形、分布柱状；
5. 切换时间范围（日/周/月/自定义）→ 数据联动；
6. 导出报表。

**台词**：
> 三个角色三套口径，统计口径写在接口文档里，可按时间维度联动。

---

## 9:20–10:00　工程与收尾

**画面**：
1. 终端执行 `pytest -q` → 全部通过（展示通过数量与覆盖率摘要）；
2. 打开 Docker Compose 配置文件，说明一键部署；
3. 文档目录：设计文档、接口文档、答辩问答。

**台词**：
> 代码分层、算法纯函数化、单元测试覆盖核心边界；一键启动，容器化部署。系统上线还差真实短信通道与密钥托管，已列入后续迭代。
