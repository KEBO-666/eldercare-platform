## 公开历史的来源

本仓库是原本地仓库的独立过滤副本。逐提交排除全部运行数据目录、SQLite数据库及WAL/SHM、下载缓存、虚拟环境和私有配置；公开版本重新补充的data目录只有两个空占位文件。原本地仓库及其历史未被改写。

过滤保留原有9次提交的顺序、作者日期和提交日期，但删除路径会改变Git提交哈希，因此公开提交并非原始哈希。映射JSON列出原哈希、公开哈希和真实日期。保留的最终源码blob与原仓库完全一致；之后的发布材料整理按实际时间另作新提交，不回填为早期开发。

11月8日历史只有基座和全模块两次粗粒度提交，不能代表完整的细粒度开发过程。11月12日已有改进快照按当时时间记录，之后的真实修复与材料整理另行保存。已有AI历史能证明一次用户优化请求和三个主题，尚不能证明三条独立、完整的人类Prompt链。部分早期中文乱码原样保留，无法读取的加密子代理消息未做重建。

## 本地运行

先安装有效的Python（已验证3.12.14），克隆本仓库并进入根目录，执行：

```powershell
git clone https://github.com/KEBO-666/eldercare-platform.git
cd eldercare-platform
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/run_dev.ps1
```

首次运行需要下载Python依赖。访问 http://127.0.0.1:8000 ，种子管理员为super，演示密码Admin@123；请仅在本地演示环境使用。详细环境选项和失败排查见根目录README及[快速开始](快速开始.md)。
