# 身份主题与基础组件优化

2026-11-13，按参赛人选定的 A/B/C/D 推荐组合，将设计样稿的配色与基础组件接入实际 Jinja2 页面，使用 Build Web Apps 插件的 frontend-app-builder 与 frontend-testing-debugging 工作流。此次基于已选定样稿完善现有组件，不新增图片概念稿或更换前端框架。

## 设计与实现

| 默认身份 | 主题标识 | 页面背景 / 主色 | 组件风格 |
|---|---|---|---|
| 老人 / 家属 | warm | `#f6f5f0` / `#3e6650` | 米白与浅绿，22px圆角，50px起步的按钮，大字号 |
| 护理员 | care | `#f1f6f6` / `#087e79` | 青绿与白色，14px圆角，清晰主次操作 |
| 网格员 / 机构管理员 | blue | `#f3f5fa` / `#3c59c5` | 浅蓝灰工作区与深蓝侧栏，适合列表与协同 |
| 街道 / 超级管理员 | night | `#0d1523` / `#88b6ff` | 柔和深蓝，浅蓝强调，文字与状态独立校准 |

主题由登录用户真实角色在服务端选择；匿名登录页和未知自定义角色使用 blue。URL里的 `theme`、`role` 等参数不改变身份、主题或权限。

`app/static/css/role-themes.css` 集中定义语义色、表面色、边框、间距、圆角与组件变体。共享的卡片、按钮、输入框、分页、状态标签、提示、弹窗、Toast、时间线与图表均使用同一套主题变量；红黄蓝预警仍用对应状态色与文字表达，避免只靠颜色传达状态。

导航使用共享 SVG 线条图标宏；保留真实菜单名称、路由与权限。桌面侧栏与手机抽屉复用同一份服务端导航，手机支持遮罩关闭、关闭按钮、Escape、Tab循环、焦点恢复和背景 inert；关闭状态的抽屉不会收到键盘焦点。JavaScript不可用时手机展示普通导航，避免入口完全消失。

按钮保留至少44px高度，老人主题至少50px；全站标准/大字/超大字偏好继续保存。支持 `prefers-reduced-motion`，打印使用浅色。深色表单、弹窗、警告和图表文字使用主题前景与背景。

## 真实内容与权限

本轮落实的是导航、卡片、按钮与配色体系，保留现有业务看板的真实统计、列表、表单和接口；不把样稿中陈阿姨、假服务量或示例健康统计写入产品。样稿的宣传横幅、英文装饰标题与方案切换器不进入实际业务页面。

导航及首页快捷操作按实际权限过滤。护理员看不到账单卡片和链接，直接访问账单页返回403；老人可以查看本人档案，入口叫“我的档案”，不显示健康读取入口。无处置权限的用户在首页看到“查看预警进展”，有处置权限的用户才显示处置用语。健康只读角色仍不能读取预警摘要或管理员审计。

同时修正旧首页账单汇总使用全局金额的问题：使用与账单页相同的可见范围与明细汇总，老人只统计本人、网格员只统计可见老人，未授予账单读取权限时不查询和展示账单汇总。

## 图表与视觉复核

图表轴、图例、提示框、网格与 SVG 降级均采用主题色；旧服务端默认色随主题适配，明确自定义色保留。每个图表都有独立的容器与窗口缩放监听，修复旧逻辑只缩放最后一个图表的问题。圆环标签改为内部百分比，图例可滚动，完整名称与数值在提示框查看，避免小卡片外侧文字被裁切。

按1440px桌面与390px手机检查首页、代表性列表和表单。Browser插件未提供，因此使用现有Playwright与本机Edge，无新增依赖。测试在独立合成数据库运行，不改实际业务数据。

对照原生1440px宽样稿检查：背景及主色、导航图标/选中态、卡片圆角与留白、按钮层级和触控高度、字号与文字对比度、手机布局和键盘操作。预览图与实页内容的差异来自真实业务数据、保留现有信息架构和权限过滤，并非使用示例数据冒充实现。首屏文字保留现有业务名称，仅调整“我的档案”和按权限选择预警操作用语；不新增营销文案。

新增 `tests/integration/test_role_ui_contract.py` 的10项检查覆盖六角色主题、身份参数不可覆写、导航可访问性、匿名保护、独立权限入口、自定义角色回退和账单范围。新增 `tests/frontend/charts.test.cjs` 的6项检查覆盖主题图表、多图表缩放、窄卡片标签、SVG及异常回退。

最终回归：685项Python测试通过，无失败、错误或跳过；覆盖7226/8000行，即90.33%。前端121项通过，Ruff通过。真实Edge六角色首页/列表/表单及交互344项全部通过；按最终样式追加四主题40项视觉复验，并针对圆环空标签底块与关闭侧栏阴影再做短复验。截图和原始报告保存在项目仓库外的本地 `../ui-review-20261113/`，不混入业务运行数据。
