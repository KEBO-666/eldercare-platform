## 发现并修复的问题

| 问题 | 真实原因 | 修复 |
|---|---|---|
| 多个页面提示报错，预约成功后跳转可能被中断 | 全局脚本定义了局部`toast()`，没有导出`App.toast`，而页面大量调用`App.toast()` | 导出统一方法。修复前Edge探测得到`typeof App.toast === 'undefined'`，修复后为`function` |
| 提示DOM存在但用户看不见 | Bootstrap的`.toast`默认样式隐藏，项目自建提示没有使用Bootstrap的`.show`机制 | 对`.toast-box .toast`显式显示并设置不透明度，保留原有动画与消失逻辑 |
| 点击后没有清楚的等待反馈，成功到刷新前可重复触发 | `App.action`没有重入检查，完成请求后立即重新启用按钮 | 检查禁用状态，显示“处理中…”和`aria-busy`；成功且即将刷新时保持禁用，失败时恢复 |
| 预约提交成功到跳转前可再次点击 | `finally`立即恢复提交按钮，跳转另有900毫秒延迟 | 成功时保持禁用，失败时恢复文案与可点击状态 |
| 处置接口失败时弹窗已关闭，输入丢失 | 模态框提交后立即关闭，没有等待接口结果 | 处置提交保持弹窗，成功后关闭刷新；失败保留措施和重试按钮 |
| 候选解释可能错误标注权重 | 权重标签固定40%/30%/20%/10%，未使用候选响应中的实际配置 | 候选明细使用响应权重，显示加权贡献；存在重点关注降权时说明倍率；顶部注明为环境默认权重 |
| 无候选时文案容易被理解为人工可绕过限制 | 原提示只建议人工指派 | 明确人工指派仍需满足全部约束，建议核对资源或调整时间 |
| 部分触控按钮低于主题宣称的44px | `.btn-sm`为38px，关闭按钮未设置最小触控尺寸 | 小按钮最小高度44px，关闭按钮最小44×44px |
| 桌面顶部“字号”可能分成两行 | 顶栏弹性布局挤压标签 | 对顶栏标签禁用文字换行 |

## 复现方式

安装Playwright到单独工具目录，保证Edge可用；录像另需Playwright可找到ffmpeg：

```powershell
& '.\.venv\Scripts\python.exe' -m pip install --target reports/chuanzhi-tools/python playwright
& '.\.venv\Scripts\python.exe' -m scripts.verify_browser
```

`--probe`仅进行前置能力及布局探测，不录制视频；`--slow-demo`在关键场景加阅读停顿，仍是自动化演示。脚本把浏览器临时目录改到本轮独立目录，以绕过本机系统临时目录的权限问题。

## 验证边界

本轮覆盖Microsoft Edge、桌面1440/1920及390px视口，没有验证所有移动设备、Safari/Firefox、真实屏幕阅读器、真实GPS和人工长时使用。未进行真实短信接入、真实穿戴设备、并发抢单、多实例任务调度或生产部署验证。预约409、处置500、非默认权重及动作等待态的部分检查是明确标记的测试注入；完整业务主线调用真实隔离应用接口。

验收工具本身经历过数据库表名、临时目录权限及慢速协议造成的响应读取失败，这些属于工具迭代，不能包装成用户发现的业务缺陷。原始失败结果保存在各次运行目录。
