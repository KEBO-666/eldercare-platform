# 登录页设计优化

日期：2026年11月13日。

用户指定参考 [sunyctf/login-demos](https://github.com/sunyctf/login-demos)，本次选取其中的 [css现代风网站登录页](https://github.com/sunyctf/login-demos/tree/main/css现代风网站登录页) 作为布局参考：[原始预览](https://sunyctf.github.io/login-demos/css现代风网站登录页/index.html)。该方案以左右双栏和清楚的表单层级为主要特点，适合现有养老平台的登录任务。

## 本项目的适配

- 桌面采用左侧社区主题、右侧账号表单；米白背景与浅绿主色沿用既有适老主题。标题、标签、输入框和主按钮有明确层级，输入及登录按钮至少58px高。
- 手机优先展示登录表单，主题说明位于表单之后，收起桌面社区图形，避免装饰占据登录首屏。
- 账号与密码仍使用原生POST到`/login`，保留`next`回跳、浏览器自动填充、用户名保留和后端错误提示。
- 显示/隐藏密码按钮可键盘操作并维护`aria-pressed`，不改密码内容；页面历史恢复时重新隐藏密码。禁用JavaScript时原生登录和演示账号展开仍可用。
- 演示账号改为原生`details`说明，默认收起；保留六类角色、账号范围和演示密码。需要帮助的用户得到联系社区管理员的提示。
- 仅登录页加载`login.css`与`login.js`，不改变认证接口、账号权限及登录后的角色主题。

## 参考与原创范围

借鉴双栏构图和表单层级，本项目的HTML、CSS、交互代码与内联SVG社区图形重新实现。未复制参考页的W3layouts/17sucai模板代码、插图、字体或脚本，不引入Google Fonts、jQuery、CDN或新依赖。布局参考仓库根许可证为MIT；下层模板还包含其他来源标注，本次不将根许可证当作这些素材的独立授权证明。

本次基于用户提供的实际参考和既有主题体系进行代码原生实现，没有生成或替换位图资产。验证采用隔离合成数据和真实Edge，Browser插件未提供，使用现有Playwright工具。

## 验证与参考差异

现有认证、Web页面和角色合同测试48项通过；登录、导航与公共脚本的JavaScript语法检查通过。真实Edge/Playwright检查67项通过，覆盖1440×1000桌面、1280×720笔记本、820×1180平板、390×844和320×740手机。

已验证：页面身份与内容、静态资源、无横向溢出、最小触控高度、六角色登录及对应主题、回跳地址、错误密码提示与输入保留、密码切换值不变、键盘操作、演示账号展开、禁用JavaScript后登录及HttpOnly认证Cookie。未将此称为真人老人可用性研究。

参考对照：保留左右双栏与轻背景表单；将原参考的蓝白、英文和办公插图替换为既有浅绿主题、中文与自绘社区SVG；按本项目任务将表单放右侧，手机优先展示表单。参考页注册入口不对应本项目现有账号管理方式，改为联系社区管理员的实际帮助说明。以上为本项目明确适配，不宣称逐像素复刻参考。
